# AI Student Placement Assistant

An AI-powered chatbot designed to help students prepare for placements through aptitude practice, technical interviews, HR interviews, resume guidance, and career suggestions.

## 🚀 Features

- Aptitude and Reasoning Practice
- Technical Interview Preparation
- HR Interview Preparation
- Resume and Career Guidance
- AI-powered responses using Groq API
- Interactive terminal-based chatbot
- Secure API key handling using `.env`

## 🛠️ Technologies Used

- Python
- Groq API
- Prompt Engineering
- python-dotenv
